## Read

q8/q8 KV with flash attention is viable in the sense that it creates context
and completes on all tested models. It is not a speed optimization on this
Mali-G715 Vulkan path. For the primary Gemma XL model, f16/f16 with flash
attention off remains faster than q8/q8 with flash attention on.

The likely role for q8/q8 KV is memory pressure reduction at larger contexts,
not raw tok/s improvement. It should only be considered for long-context server
experiments where f16 KV memory becomes the limiting factor.

Bonsai 4B remains interesting as a compact conversational model, but Allan's
qualitative testing found its tool-calling and agentic behavior weaker than the
Gemma model. That makes it a poor default for Pi-agent workflows even though it
is a good file-size/value tradeoff for chat.

Bonsai 8B did not crash `llama-bench` in this q8/q8 KV pass, but its throughput
is low enough that prior `llama-server` instability is still a serious
day-to-day viability concern.
